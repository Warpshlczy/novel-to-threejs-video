# 电影级分镜与故事调度

> 目标：让每个镜头都有**戏剧职责**，让每次切换都有**动机**，让观众的信息获取顺序**被设计过**。
> 不是"把小说分段拍"，而是"用镜头重新讲一遍"。

## 1. 镜头语法

### 1.1 景别（按人物在画面中的比例）

| 代号 | 名称 | 取景 | 用途 |
|---|---|---|---|
| ELS | 大远景 | 人物 <1/8 画面高 | 建立空间、压迫感、孤独 |
| LS | 远景 | 人物 1/4–1/2 | 环境关系、走位 |
| MLS | 中远景 | 膝盖以上 | 动作与调度 |
| MS | 中景 | 腰以上 | 对话主力 |
| MCU | 中近景 | 胸以上 | 情绪 |
| CU | 特写 | 肩以上 | 心理 |
| ECU | 大特写 | 眼/手/物 | 关键信息、悬念 |

### 1.2 角度

- **平视**：平等、客观；对话默认。
- **低角度**：权力、威胁、英雄化；威胁、权威、巨物。
- **高角度**：弱小、被审视、命运感；海面上的船。
- **顶视**：几何构图、宿命、冷。
- **荷兰角（倾斜 5–20°）**：失衡、精神异常；全片不超过 3 次。

### 1.3 焦段（等效全画幅）

| 焦段 | 观感 | 用途 |
|---|---|---|
| 18–24mm | 夸张透视、不安 | 狭窄空间、巨物压迫、失控场面 |
| 35mm | 纪实、自然 | 走位、群像 |
| 50mm | 中性、接近人眼 | 对话主力 |
| 85mm | 压缩、亲密 | 情绪特写 |
| 135mm+ | 强压缩、窥视 | 远景孤立、监视感 |

**规则**：同一场戏焦段变化不超过两档；焦段突变必须对应情绪突变。

### 1.4 运镜（每种都要写"为什么"）

固定 / 推（push in）/ 拉（pull out）/ 摇（pan）/ 俯仰（tilt）/ 移（track）/ 升降（crane）/ 手持（handheld）/ 斯坦尼康（steadicam）。

- 推：靠近内心、逼近真相。
- 拉：抽离、揭示环境、无力感。
- 手持：失控、临场；恐怖片峰值常用。
- 固定：让画面内的运动说话；对话场默认。

### 1.5 构图

- 三分法 / 中心对称 / 引导线 / 负空间 / 框中框 / 前景遮挡。
- **负空间**是恐怖片最便宜的武器：让人物只占画面 1/5，其余交给环境。
- 前景（雨、缆绳、蒸汽）能立刻增加层次与"摄影机在场感"。

## 2. 资产能力驱动分镜（v5）

> 分镜不是先写完再找资产，而是**按资产等级设计画幅**。把弱资产放进大特写，是最常见的翻车方式。

### 2.1 画幅上限

| 资产等级 | 允许的最大景别 | 允许的最长焦段 | 说明 |
|---|---|---|---|
| T0 | 不进成片 | — | 只用于 previz |
| T1 | MS | 50mm | 剪影、背影、远景群像 |
| T2 | MCU | 85mm | 对话主力；不做 ECU |
| T3 | ECU | 任意 | 唯一能撑住真实人脸特写的等级 |

### 2.2 配额

| 指标 | 上限 | 超出时 |
|---|---:|---|
| CU + ECU 占比 | ≤25% | 换成 MCU + 插入镜 |
| 85mm 及以上占比 | ≤30% | 降到 50mm，靠构图压缩 |
| 单角色 CU/ECU 连续出现 | ≤2 镜 | 中间插反应/物件/环境 |

> 例外：全部主角色均为 T3 且其出场时长 ≥60% 时，配额可放宽到 35%。放宽要写进 `quality.lock.json`。

### 2.3 资产不够时的替代语法

想给特写，但资产只有 T1/T2——不要硬切。按下面替换，叙事效果往往更好：

| 原本想拍 | 资产不足时改拍 | 为什么更好 |
|---|---|---|
| 脸部特写（情绪） | 手部特写（攥紧/松开） | 手比脸更会演，且 T2 即可 |
| 脸部特写（震惊） | 背影 + 肩部停顿 | 留白让观众自己补情绪 |
| 眼睛特写 | 眼睛倒影里的物件 | 信息量更大，且只需局部资产 |
| 人物中景 | 剪影 + 逆光 | 光影替代细节 |
| 人物对话 | 过肩 + 听者反应 | 覆盖更省，剪辑更活 |
| 角色全身 | 衣物/鞋/随身物 | 用道具承担人物信息 |
| 群像 | 局部（几双手/几个背影）+ 声音 | 声音建立规模，画面只给证据 |

**原则：当画面给不出细节时，把信息交给声音、构图和剪辑，而不是交给更近的镜头。**

### 2.4 分镜卡新增字段

```jsonc
{
  "id": "S12",
  "shotSize": "MCU",
  "lens": 85,
  "subjectTier": "T2",          // 本镜主体的资产等级
  "faceBudget": false,          // 是否消耗"清晰人脸"配额
  "assetFallback": "手部特写"    // 若主体升级失败，退回到什么
}
```

- `subjectTier` 低于景别要求时，`validate_shots.py` 报 error。
- `faceBudget: true` 的镜头数量受 §2.2 配额约束。

### 2.5 自检

- [ ] 每个 CU/ECU 的主体都是 T3
- [ ] 每个 85mm 镜头的主体 ≥T2
- [ ] CU+ECU ≤25%，85mm ≤30%
- [ ] 没有"因为想拍脸所以拍脸"的镜头；每个特写都有信息职责
- [ ] 弱资产场景已用替代语法（手/背影/剪影/物件/声音）

## 3. 调度（Blocking）

1. 先画**平面走位图**：锚点（门、舵轮、尸体位置）、各人相对位置、朝向、距离。
2. 定**轴线**：一场戏一条主轴（如船首—船尾），摄影机只在同一侧工作；越轴必须用中性镜头或运动过渡交代。
3. **视线匹配**：A 看画右，B 必须看画左；否则观众会以为两人没在对视。
4. **30° 规则**：同一主体两次切换，机位角度差 ≥30°，否则会"跳帧"。
5. **入出画方向**：向左走出画，下一镜应从画右进入（除非刻意制造断裂）。
6. **景深分层**：前景（遮挡/雨）/ 中景（主体）/ 背景（环境叙事），三层都要有事发生。

## 4. 剪辑

### 4.1 切点动机（五选一，可叠加）

| 动机 | 说明 |
|---|---|
| 动作切 | 在动作中切，掩盖剪辑点 |
| 视线切 | 顺着人物视线切到所见 |
| 声音切 | 用声音提前/延后带入下一镜（J/L cut） |
| 图形匹配 | 形状/颜色/运动方向相似 |
| 节奏切 | 情绪需要加速或停顿 |

### 4.2 J-cut / L-cut

- **J-cut**：下一镜的声音先进来，画面后到 → 预示、压迫。
- **L-cut**：上一镜的声音延续到下一镜 → 余韵、空间连续。

恐怖片里，J-cut 是"什么东西先来了"的最低成本实现。

### 4.3 节奏曲线

| 段落 | 平均镜长 | 切点密度 |
|---|---|---|
| 铺陈 | 4–8s | 8–15 cuts/min |
| 推进 | 2–4s | 15–25 cuts/min |
| 峰值 | 0.8–1.5s | 40–60 cuts/min |
| 余韵 | 5–10s | 5–10 cuts/min |

写完分镜后用 `PySceneDetect` 对成片实测切点，和曲线对照。

## 5. 故事调度（比镜头更上层）

### 5.1 信息释放表（必须写）

| 秒 | 观众知道 | 角色知道 | 落差用途 |
|---|---|---|---|
| 0–15 | 世界正常（基线） | 同左 | 建立参照 |
| 32 | 环境出现第一个异常 | 只有配角注意到 | 悬念（观众领先） |
| 61 | 威胁的真实规模 | 主角仍无反应 | 塑造主角异常 |

**写法**：先填"观众知道什么 / 角色知道什么"，两者差值就是悬念。悬疑用"观众领先"，惊悚用"观众落后"。

> 通用示例（都市悬疑）：0–15 女主独自回家；32 观众看到门锁被撬、女主没注意；61 观众看到衣柜缝里的眼睛、女主还在打电话。
> 通用示例（科幻）：0–20 飞船例行巡航；40 观众看到舷窗外的影子、值班员在看仪表；70 观众知道那不是影子，值班员仍以为是故障。

**悬念 = 观众知道得比角色多；惊讶 = 观众知道得比角色少。** 恐怖/悬疑主要用前者。

### 5.2 伏笔与回收

- 每个伏笔在 3 个位置出现：埋（不经意）、强化（被注意到）、回收（改变意义）。
- 道具线索要"被使用"而不是"被展示"：打火机先点烟（日常）→ 关键时刻点不着（强化）→ 最后点燃（回收）。
  任何道具都能套用：**先给它日常功能，再让它在压力下失效，最后让它改变意义。**

### 5.3 空间揭示顺序

先给局部（手、仪表、门缝），再给整体（房间/空间），最后给外部（环境全貌）。观众的空间感是被"拼"出来的，不是被"告"知的。

### 5.4 恐怖/悬疑专项

- **延迟揭示**：威胁第一次只给 0.5 秒的局部，第二次给影子，第三次才给全貌。
- **负空间**：让人物偏居画面一角，其余留灰。
- **画外音先行**：先听到，再看到；声音比画面早 0.3–0.8s。
- **构图失衡**：主体压在画面边缘，制造"要出事"的预感。
- **静默**：峰值前 0.5–1s 抽空所有声音，比加音效更有效。

## 6. 分镜卡片（电影级字段）

```jsonc
{
  "id": "S07",
  "scene": "SC003",
  "duration": 3.2,
  "shotSize": "ECU",                // 大特写：门缝
  "angle": "eye",
  "lens": 85,                       // 等效焦距
  "height": 1.55,                   // 机位高度（米）
  "distance": 0.8,                  // 主体距离
  "cameraMove": "static",
  "composition": "center, negative-space-left",
  "blocking": [{ "who": "lead", "at": "door", "facing": "in" }],
  "beat": "门缝里的眼睛眨了一下",
  "newInfo": "观众确认屋内有人",
  "cutReason": "reaction-cut（先给反应，再给所见）",
  "soundBridge": "J-cut: 呼吸声提前 0.4s",
  "lightMotivation": "走廊冷光 + 门缝暖光",
  "subjectTier": "T3",              // 本镜主体等级；ECU 必须 T3
  "faceBudget": true,               // 消耗"清晰人脸"配额
  "assetFallback": "insert-keyhole",// 主体升级失败时退回的覆盖镜头
  "coverage": ["insert-keyhole", "reaction-lead", "empty-hall"],
  "assets": ["door", "eye-rig", "lead"],
  "continuity": ["门缝宽度不变", "眼睛只出现一次"]
}
```

> 字段是固定的，**内容随题材替换**。这张卡片的字段就是分镜校验器的输入；缺 `cutReason`、缺 `coverage`、连续同景别、**景别超出 `subjectTier` 上限**都会在校验时报错。

## 7. 分镜完成前的自检

- [ ] 每镜有唯一职责，删掉它剧情/情绪会缺一块
- [ ] 每镜有 `cutReason`，且不是"因为该切了"
- [ ] 同场戏轴线一致；越轴有交代
- [ ] 连续两镜景别不同、角度差 ≥30°
- [ ] 每场至少 1 个插入镜或反应镜
- [ ] 镜长分布符合段落曲线
- [ ] 信息释放表填完，观众知情时机可核对
- [ ] 每个伏笔有埋/强化/回收三处
- [ ] 峰值前有静默设计
- [ ] 声音有 J/L cut 设计
- [ ] 每个 CU/ECU 的主体是 T3，每个 85mm 镜头主体 ≥T2
- [ ] CU+ECU ≤25%，85mm ≤30%
- [ ] 弱资产的镜头已用替代语法（手/背影/剪影/物件/声音）
