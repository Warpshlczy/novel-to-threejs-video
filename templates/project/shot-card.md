# 分镜卡模板（每镜一张）

> 复制到 `design/05-shots.md`，每镜一节。字段与 `story.schema.json` 的 `shots` 一一对应。
> 填写顺序：职责 → 信息 → 机位 → 调度 → 声音 → 连续性。

## S__ · 镜头名

| 字段 | 值 |
|---|---|
| 场次 | SC__ |
| 时长 | __ s（写目标值，实测后由 build_timeline 重排） |
| 景别 | ELS / LS / MLS / MS / MCU / CU / ECU |
| 角度 | eye / low / high / top / dutch |
| 焦段 | __ mm（等效全画幅） |
| 机位高度 | __ m |
| 主体距离 | __ m |
| 运镜 | static / push / pull / pan / tilt / track / crane / handheld（写理由） |
| 构图 | 三分 / 中心 / 引导线 / 负空间 / 框中框 / 前景遮挡 |
| 轴线 | __（一场一条主轴） |
| 摄影机侧 | A / B / neutral |
| 走位 | 谁在哪个锚点、朝向、距离 |
| 唯一职责 | 删掉这一镜，剧情/情绪会缺什么 |
| 观众新信息 | 这一镜让观众第一次知道什么 |
| 切镜动机 | 动作切 / 视线切 / 声音切 / 图形匹配 / 节奏切（可叠加） |
| 声音桥 | J-cut / L-cut（提前或延后多少秒） |
| 光线动机 | 画面内什么光源在照明 |
| 覆盖 | 插入镜 / 反应镜 / 空镜 |
| 资产 | 角色 / 场景 / 道具 ID |
| 连续性 | 可原样粘贴的锁定短语（不得改写） |

## 起点 → 唯一动作 → 终点

- 起点：画面里已经有什么（人物姿态、持物、光位）
- 唯一动作：这一镜只发生一件事
- 终点：下一镜可信的起点

## 自检

- [ ] 有唯一职责，且不是"过场"
- [ ] `cutReason` 不是"该切了"
- [ ] 与上一镜景别不同、角度差 ≥30°
- [ ] 同场轴线未翻转，或已交代
- [ ] 对白不超过镜长 75%
- [ ] 连续性短语与《视觉设定》逐字一致
