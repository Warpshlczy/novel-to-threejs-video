## 7. 验收清单

**技术**
- [ ] 任意 `t` 可重建（`computeState` 幂等）
- [ ] seek 后声画误差 ≤80ms
- [ ] 暗部无 banding，高光有细节
- [ ] 同角色跨镜同实例/同材质/同光照
- [ ] 纹素密度偏差 ≤20%
- [ ] 帧率达标（p95 掉帧 <5%）

**叙事**
- [ ] 每镜有唯一职责与 `cutReason`
- [ ] 连续两镜景别不同、角度差 ≥30°
- [ ] 轴线零违规
- [ ] 信息释放表填完
- [ ] 伏笔三处齐全
- [ ] 峰值前有静默

**交付**
- [ ] MP4 可离线播放
- [ ] SRT 与音频同源
- [ ] -14 LUFS / ≤-1 dBTP
- [ ] 字幕安全区与对比度合格
